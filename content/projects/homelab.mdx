# 🏠 Project Homelab

**LAN-first • Secure • Modular • Offline-capable Personal Cloud**

Homelab is a self-hosted, LAN-based multi-user system designed to function as a **private cloud and automation hub** — fully operational without internet dependency.

Built with a systems-first mindset, it emphasizes **security, modularity, background processing, and extensibility**, making it suitable for both personal infrastructure and scalable architectural experimentation.

---

## 🚀 Vision

Create a **secure, offline-first infrastructure layer** that supports:

- Private multi-user storage
- Real-time communication
- Role-based collaboration
- Modular automation and AI extensions

Homelab is not just a file server — it’s a foundation for building a **personal distributed system inside a LAN.**

---

## 🧱 Core Architecture

- **Backend:** Node.js + Express (TypeScript)
- **Database:** PostgreSQL (Prisma ORM)
- **Caching & Jobs:** Redis + BullMQ
- **Storage:** Local filesystem (extensible to object storage)
- **Auth:** JWT (Access + Refresh token model)
- **Infra:** Dockerized services (server, workers, database, redis)

Designed with:

- Clean modular folder structure
- Background worker separation
- Scalable API design
- Strong type safety
- Production-grade logging
